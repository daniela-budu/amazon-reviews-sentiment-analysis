## Overview

This project presents an end-to-end Natural Language Processing (NLP) pipeline developed in **R** to automatically collect, preprocess and analyse customer reviews from Amazon UK.

The workflow combines web scraping, text preprocessing, dictionary-based sentiment analysis, context-aware sentiment analysis and supervised machine learning to evaluate customer opinions towards a real consumer product.

This project was developed as part of the **Text Mining and Sentiment Analysis** course at the **University of Bergamo**.

## Project Highlights

- Automated web scraping of Amazon UK reviews
- Text cleaning and preprocessing
- Dictionary-based sentiment analysis (Bing Lexicon)
- Context-aware sentiment analysis (UDPipe)
- Supervised sentiment classification using Naive Bayes
- Performance comparison between different NLP approaches

## Research Question

> Which sentiment analysis approach performs best on Amazon UK customer reviews?

The objective is to compare different Natural Language Processing techniques and evaluate their strengths and limitations on a real-world dataset.
